How to use:
1. Upload this whole folder to Netlify, Cloudflare Pages, Neocities, or GitHub Pages.
2. Edit index.html and replace the placeholder links with your real Steam, Spotify, X, Discord invite, and Throne links.
3. Put your song file in assets/ and name it song.mp3, or edit the audio source filename in index.html.
4. The background file uploaded here is named .gif, but it appears to be a still PNG internally. Replace assets/background.gif with a true animated GIF if you want full motion.
